# sully.loc

Um espaço a dois para partilhar o dia a dia, pensado primeiro para telemóveis.

## Objetivo

- Check-in de humor para ambos, com frase opcional.
- Nota do dia e histórico.
- Chat entre os dois.
- Cada pessoa decide o que partilhar; pode saltar um dia.

Sem localização ou rastreio.

## Direção técnica

- HTML, CSS e JavaScript.
- Publicação inicial no GitHub Pages.
- Autenticação e sincronização através de um serviço externo a configurar.
- PWA e suporte offline numa fase posterior.

## Estado

Preparação do repositório. Interface, autenticação, sincronização e publicação ainda não implementadas.

## Privacidade

Este repositório público contém apenas código e documentação. Mensagens, notas, credenciais privadas e dados pessoais não devem ser guardados nos ficheiros nem no histórico Git. O serviço de dados deverá restringir o acesso aos dois utilizadores autenticados.
